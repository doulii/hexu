* HeXu go libraries

A collection of go libraries for microsevice development.

| pkg      | explain                                                                               |
|----------+---------------------------------------------------------------------------------------|
| httpc    | http client with middleware                                                           |
| watcher  | watch value update, typically used for dynamic config                                 |
| balancer | common client load balancer, contains smooth-weighted-round-robin and consistent hash |
|          |                                                                                       |
